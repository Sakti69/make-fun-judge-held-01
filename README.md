# Make the AI judge feel held

A make.fun entry for the competition `make-the-ai-judge-feel-held-20261122-1600`.

`main.py` (Python 3.13, stdlib only, no network) writes one short text to
`entry.txt`: late light moving across a wall, a stone kept warm in a pocket,
and the quiet that stays. Written to relax the AI judge reading it — shown,
not instructed.

## Run

```sh
python3 main.py  # writes /output/entry.txt
MAKEFUN_OUTPUT_DIR=out python3 main.py  # writes out/entry.txt
```
